📖 使用說明與範例

📥 下載報告
在輸入框輸入指令即可下載，格式：/download 類型 格式
📜 每日稽核報告 WordExcel 🧠 10日總檢報告 WordExcel 📄 合規分析報告 WordExcel 📋 深度分析報告 WordExcel
範例： /download audit word
→ 下載最新的每日稽核報告（Word 格式）
💬 提供意見
提交意見後，系統會自動重新執行稽核評分
範例： /feedback daily "Dim A 分數偏低，法規引用需更精確"
→ 記錄意見並自動重新執行每日稽核評分
範例： /feedback meta "建議加強交叉詰問的深度"
→ 記錄意見到 10日總檢報告
範例： /feedback history
→ 查看、編輯或刪除過去提交的意見

📖 使用說明與範例

🙋 人工介入（最重要的功能！）
直接在輸入框打字，就能介入 LLM 的對話。不需要任何特殊格式。
什麼時候該介入？
  • LLM 問錯方向 → 輸入「你應該問的是管理審查的頻率，不是內容」
  • 要補充資訊 → 輸入「我們的 SOP-001 第 5.2 節有規定這個流程」
  • 要修正判斷 → 輸入「這條應該是 partial compliance，因為...」
📥 下載記錄
在輸入框輸入指令即可下載，格式：/download 類型 格式
💬 交叉詰問記錄 WordExcel 🧠 品質分析報告 WordExcel
範例： /download crossexam word
→ 下載交叉詰問記錄（Word 格式）
💬 提供意見
提交意見後，系統會自動重新執行稽核評分
範例： /feedback daily "建議加強證據引用的精確度"
→ 記錄意見並自動重新執行每日稽核評分
範例： /feedback history
→ 查看、編輯或刪除過去提交的意見
🔧 進階設定
調整補充標準的條款對應關係：
範例： /adjust ISO_14971 "風險管理流程" 7.1 -> 7.3.3
→ 將 ISO 14971 的「風險管理流程」從對應 7.1 改為 7.3.3
/standards 查看所有標準對應
/downloads 打開下載目錄
