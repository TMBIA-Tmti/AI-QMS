📖 Usage Guide & Examples

Human Intervention (Most Important!)
Type directly in the input box to intervene in the LLM conversation. No special format required.
When should you intervene?
  • LLM asks the wrong direction → type "You should be asking about the frequency of management reviews, not the content"
  • Need to add information → type "Our SOP-001 section 5.2 defines this process"
  • Need to correct a judgment → type "This should be partial compliance, because..."
