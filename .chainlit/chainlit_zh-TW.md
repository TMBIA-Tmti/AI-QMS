# AI-QMS 品質管理系統 v3.1.0

歡迎使用 AI-QMS Phase 1 文件管制系統！

## 功能概覽

| 功能 | 說明 |
|------|------|
| 文件上傳 + OCR | 支援 PDF, Word, Excel, PowerPoint, 圖片 |
| 版本控制 | 自動偵測進版、重複文件檢查 |
| 簽章偵測 | 15+ 語言簽章/印章辨識 |
| 法規掃描 | 自動掃描文件引用的法規標準 |
| 文件更動紀錄 | SHA-256 防篡改稽核鏈 |
| LLM 智能對話 | 16+ AI 提供商支援 |

## 使用方式

- **主系統 (Main Agent)** — 文件列表、搜尋、作廢、LLM 對話
- **文件管制 (Doc Control)** — 文件上傳、OCR 處理、版本控制

點擊頂部的 Profile 選擇器切換功能模組。
