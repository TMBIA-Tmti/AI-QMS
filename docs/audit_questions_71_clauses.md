## 一、抽題機制說明

### 運作原理

`get_audit_question(clause, seed)` 函式依**日期種子**從每條款的 `audit_questions` 清單中輪替抽題：

```python
def get_audit_question(clause: dict, seed: int | None = None) -> str:
    questions = clause.get("audit_questions") or []
    if len(questions) > 1:
        if seed is None:
            seed = int(date.today().strftime("%Y%m%d"))  # e.g. 20260413
        return questions[seed % len(questions)]
    if questions:
        return questions[0]
    return clause.get("audit_question", "")
```

| 參數 | 說明 |
|------|------|
| `seed` | 預設為當天 `YYYYMMDD`（如 `20260413`） |
| 輪替方式 | `seed % 題目數`，每條款共 2 題，奇偶日各抽一題 |
| 同日一致性 | 同一天所有文件抽到同一題，確保稽核主題聚焦 |
| 向下相容 | 若 `audit_questions` 不存在，回退至 `audit_question` 單一欄位 |

### 覆蓋狀況

| 項目 | 數量 |
|------|------|
| ISO 13485:2016 總條款數 | **71** |
| 支援輪替（≥ 2 題）| **71** |
| 僅單題 | **0** |

### 題目分布

每條款固定 2 題：
- **Q0（偶數日）**：條款核心符合性問題（與 `audit_question` 相同，向下相容）
- **Q1（奇數日）**：從過程有效性、風險升級、追溯性、執行證據等角度切入的第二視角問題

### ⚠️ 目前整合狀況

> **`get_audit_question()` 已定義但尚未整合至各報告**。
> 目前所有報告（Daily Audit、Cross-Exam、Regulatory List、Risk Report、P0–P5）均直接讀取 `clause.get("audit_question")` 靜態欄位（永遠是 Q0），
> 尚未呼叫 `get_audit_question()` 輪替函式。
> **需在 `comparison_table.py` 第 166、200 行將靜態讀取改為呼叫 `get_audit_question()`，各報告才會真正輪替。**
